On-device AI · SDK

KISA 온디바이스 딥페이크 탐지 SDK 과제

SDK 설계·개발 메인 / 모델 경량화 서브 · 2026.04 ~ 현재

서버 없이 Android/iOS 단말에서 딥페이크를 탐지하는 SDK. AI 딥페이크 탐지(2024)의 후속으로 3사가 공동 수행하는 KISA 과제이며, SDK 개발과 탐지 모델을 라온시큐어가 담당한다. 모델 교체가 SDK 릴리즈에 종속되지 않도록 구조를 분리했다. Android/iOS와 서로 다른 하드웨어에서도 동일한 모델 동작을 재현할 수 있도록 SDK를 설계하고 있다.

Android + iOSCross-platform SDK
≤ 1e-5플랫폼 간 기준 출력 재현 오차

SDK 설계

  • Kotlin/Swift 인터페이스 – C++ 공유 코어 – 추론 백엔드(HAL) 3계층.
  • Android/iOS가 동일한 C++ 탐지 로직을 사용하도록 플랫폼별 코드와 공통 코어를 분리.
  • model_config에 전처리·입출력·런타임 설정을 정의해 모델·config·golden I/O 3개 파일만으로 SDK 코드 수정 없이 모델을 교체.

추론 런타임 · 가속

  • NNAPI/CoreML 가속 우선 + CPU(XNNPACK) fallback 구조.
  • 특정 단말에서 NNAPI 드라이버 문제를 확인해 ONNX Runtime 단일 구조 대신 여러 런타임을 선택할 수 있도록 확장.
  • ONNX Runtime/TFLite/CoreML 중 단말·모델 특성에 맞는 런타임을 선택할 수 있도록 설계.

크로스플랫폼 정합

  • ML Kit/Vision 얼굴 검출 차이로 동일 영상의 점수가 달라지는 문제 확인.
  • crop 기하 보정으로 모델팀 기준 출력을 1e-5 이내 오차로 재현.
  • 검출기는 자체 경량 MTCNN C++ 공유 구조로 통일하는 방향 설계.

성능 측정 · 배포 안정성

  • 추론 지연·FPS·메모리·콜드 스타트·배터리 사용량을 측정하고 출력 회귀 테스트를 구성.
  • AES-256-GCM 암호화 배포, 메모리 내 복호화, 모델 서명 검증.
  • A/B slot 기반 OTA와 실패 시 이전 모델로 되돌리는 구조.
  • 모델 경량화(서브) — 양자화·프루닝·지식증류를 온디바이스 지연·메모리 제약에 맞춰 실험.
