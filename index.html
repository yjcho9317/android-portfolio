기술 상세

SDK · 추론 구조

  • Kotlin/Swift 인터페이스 → C++ 공통 코어 → ONNX Runtime 추론 백엔드.

모델 배포 · 무결성

  • model_config에 전처리·입출력 설정을 정의하고 model + config + golden I/O 단위로 교체.
  • mVaccine 서명 검증 구조를 계승해 AES-256-GCM 암호화 + RSA-PSS 서명 검증을 적용하고, 샘플링 해싱 대신 전체 SHA-256 검증 후 스테이징 교체 · 실패 시 자동 롤백.

단말 · 런타임 호환성

  • Execution Provider 우선순위를 config로 분리해 모델·단말 조건에 따라 NNAPI/XNNPACK fallback을 제어.
  • armeabi-v7a·x86 32bit ABI 지원. ARM32 SIGBUS를 ORT 그래프 최적화 문제로 추적해 32비트에서 문제 최적화만 비활성화하고 64비트 최적화는 유지.

출력 검증 · 멀티모달

  • 협력사와 결과가 다른 구간은 원본 코드 재현과 입력 소스 교체로 오디오 디코딩 조건까지 원인을 좁힘.
  • 오디오·비주얼 전처리를 C++ 공통 코어로 이식하고 정합성 검증: 멜 상대오차 1e-4, 컬러맵 바이트 일치.
  • 얼굴 검출기 경량화 결과를 공통 검출기에 반영.
