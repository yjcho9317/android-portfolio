기술 상세

SDK · 추론 구조

  • Kotlin/Swift 인터페이스 → C++ 공통 코어 → ONNX Runtime 추론 백엔드.

모델 배포 · 무결성

  • 설정 파일에 전처리·입출력 규격을 정의하고 설정 + 암호화 모델 + 서명을 패키지 하나로 교체. 모델팀이 제공한 기준 입출력(golden I/O)으로 모델 검수·회귀 테스트.
  • mVaccine의 서명 형식(RSA-PSS)을 계승하고, AES-256-GCM 봉투 암호화는 자체 설계.
  • 샘플링 해싱 대신 전체 SHA-256 검증 후 스테이징 교체 · 검증 실패 시 기존 설치본 유지, 로드 실패 시 번들 재설치로 복구.

단말 · 런타임 호환성

  • Execution Provider 우선순위를 config로 분리. NNAPI 벤더 드라이버 크래시 확인 → Android는 XNNPACK 우선. iOS는 CoreML 우선, 실패 시 CPU로 fallback.
  • Android 15+ 16KB 페이지 크기 대응 · 기존 앱 호환 유지.
  • armeabi-v7a·x86 32bit ABI 지원. ARM32 SIGBUS를 ORT 그래프 최적화 문제로 추적해 32비트에서 문제 최적화만 비활성화하고 64비트 최적화는 유지.

출력 검증 · 음성·영상 전처리

  • 오디오·비주얼 전처리를 C++ 공통 코어로 이식하고 정합성 검증: 멜 상대오차 1e-4, 컬러맵 바이트 일치.
  • 경량화한 얼굴 검출기를 공통 코어 검출기에 반영.
